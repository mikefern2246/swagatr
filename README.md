# WebGame Controller v9

รันเว็บเกมหลายตัวในโปรแกรมเดียว แบ่งจอได้ ซ่อนหน้าจอ (Stealth) โดยเกมยังรันต่อ และแจ้งเตือนเมื่อจอไหนได้ไอเทม

## วิธีใช้

1. ติดตั้ง Node.js (https://nodejs.org) ถ้ายังไม่มี
2. แตก zip แล้วดับเบิลคลิก `start.bat` (ครั้งแรกจะติดตั้งตัวโปรแกรมให้อัตโนมัติ)
   หรือเปิด Terminal ในโฟลเดอร์นี้แล้วรัน `npm install` ตามด้วย `npm start`
3. ใส่ URL เกม กด "เพิ่มเกม"

## แบ่งจอ (Split)

เมนู `▣ จอเดียว` แถบบนขวา เลือกได้: จอเดียว / 2 จอ ซ้าย|ขวา / 2 จอ บน/ล่าง / 3 จอ / 4 จอ (2×2)

- เกมแสดงตามลำดับในรายการ (#1, #2, …) เกมที่เกินจำนวนช่องจะรันเบื้องหลัง กดแท็บเกมนั้นเพื่อสลับเข้ามาในช่อง
- ปุ่ม ◀ ▶ ที่หัวช่อง ย้ายตำแหน่งเกม
- ปุ่ม ⛶ หรือดับเบิลคลิกหัวช่อง: ขยายจอนั้นเต็มพื้นที่ กดซ้ำเพื่อกลับไปแบ่งจอ
- แต่ละช่องมี Stealth, รีโหลด, ปิดเสียง, ปิดเกมของตัวเอง

## ปรับขนาด

- **ขนาดภาพเกมต่อจอ**: ปุ่ม − / + ที่หัวช่อง (25%–300%) คลิกตัวเลขเพื่อรีเซ็ตเป็น 100% ค่าถูกจำไว้
- **ขนาดหน้าต่างโปรแกรม**: เมนู `🖥 ขนาดหน้าต่าง…` เลือก 1280×720 / 1600×900 / 1920×1080 / ขยายสูงสุด / เต็มจอ

## แจ้งไอเทม (ได้ของ / ดรอป)

เปิดแผง `📦 ไอเทม` ทางขวา

- **📜 ล่าสุด**: ไอเทมที่ได้ล่าสุด พร้อมรูป เวลา และจอที่ได้
- **📊 สรุป**: จำนวนรวมแยกตามจอและชนิดไอเทม กรองเฉพาะจอได้ ส่งออก CSV ได้
- **แจ้งเตือน**: ขึ้นป๊อปอัปของระบบ (ชื่อจอ + รายการไอเทม + รูป) แม้ในขณะ Stealth ได้เป็นกลุ่มทุก ~1 วินาทีเพื่อไม่ให้รัว ตั้งให้แจ้งเฉพาะจอที่ Stealth ได้ คลิกที่แจ้งเตือนเพื่อกระโดดไปจอนั้น
- มีชิปแสดงไอเทมล่าสุดบนแถบบน และตัวเลขแดงที่ปุ่ม 📦 เมื่อมีไอเทมใหม่ขณะแผงปิดอยู่

### โปรแกรมรู้ได้อย่างไรว่าได้ไอเทม

โปรแกรมไม่รู้จักเกมนี้โดยเฉพาะ จึงจับจาก 2 ทาง แล้วใช้ "กฎ" (RegExp) ที่แก้ได้ในแท็บ ⚙ ตั้งค่า:

1. **ข้อความที่ขึ้นบนหน้าเกม** (ล็อกแชต/ระบบ/ป๊อปอัปในเกม) เช่น `ได้รับ Red Potion x3`
2. **ข้อความที่เกมรับผ่าน WebSocket** (ถ้าเกมส่งเป็น JSON/ข้อความธรรมดา)

กฎเริ่มต้นจับคำว่า ได้รับ / เก็บได้ / ดรอป / obtained / received / looted ฯลฯ และแยกชื่อกับจำนวน (`x3`, `×3`) ซึ่งเป็นเพียงการเดา อาจไม่ตรงกับรูปแบบข้อความของเกมนี้

**ขั้นตอนปรับให้ตรงกับเกม (แนะนำทำครั้งแรก)**

1. แท็บ ⚙ ตั้งค่า → ติ๊ก "โหมด Debug" → บันทึก
2. เล่นให้ได้ไอเทม 1 ครั้ง แล้วดูกล่อง "ข้อความดิบจากหน้าเกม" หาบรรทัดที่มีชื่อไอเทม
3. แก้กฎให้ตรงกับรูปแบบนั้น (ใช้ `(?<item>...)` เป็นชื่อ และ `(?<qty>...)` เป็นจำนวน) → บันทึก → กด 🔔 ทดสอบแจ้งเตือนเพื่อเช็กว่าระบบแจ้งเตือนทำงาน
4. ปิด Debug เมื่อใช้งานได้แล้ว

ถ้าหาบรรทัดไม่เจอเลยทั้งแบบ `dom` และ `ws` แปลว่าเกมน่าจะวาดข้อความบน `<canvas>` และส่งข้อมูลแบบไบนารี ซึ่งอ่านไม่ได้ด้วยวิธีนี้

### รูปไอเทม

หาจากรูปที่อยู่ในแถวข้อความเดียวกัน, รูปที่มี `alt`/`title` ตรงกับชื่อไอเทม (ในช่องเก็บของ), รูปพื้นหลัง CSS, หรือฟิลด์รูปใน JSON (`icon`, `image`, …) ถ้าเกมไม่เปิดเผยรูปในจุดเหล่านี้ จะแจ้งเตือนโดยไม่มีรูป (ถ้าเคยเห็นรูปของไอเทมชื่อเดียวกันมาก่อน จะใช้รูปนั้น)

### ข้อจำกัดที่ควรรู้

- ช่วง 5 วินาทีแรกหลังโหลดเกม จะไม่แจ้งไอเทม เพื่อกันประวัติแชตเก่าที่โหลดขึ้นมาถูกนับเป็นของใหม่
- ข้อความแชตของผู้เล่นคนอื่นที่พิมพ์ว่า "ได้รับ ..." อาจถูกนับด้วย ใช้ช่อง "ข้อความที่ไม่นับเป็นไอเทม" กรองออก
- ข้อความเดียวกันเป๊ะๆ ที่เกิดซ้ำภายใน ~1 วินาที อาจถูกนับเป็นครั้งเดียว
- "ตรวจจากโครงสร้าง JSON ของ WebSocket (ทดลอง)" เสี่ยงนับผิด ควรเปิดเมื่อกฎข้อความจับไม่ได้เท่านั้น

## Stealth

| โหมด | เกมรันอะไรต่อ | ประหยัด GPU |
|---|---|---|
| รันต่อเต็มที่ (ค่าเริ่มต้น) | ทุกอย่าง รวมลูปแอนิเมชัน | น้อย เพราะเกมยังสั่งวาดภาพอยู่ |
| ซ่อนจริง | ตัวจับเวลา เครือข่าย WebSocket | มากที่สุด แต่ลูปที่ใช้ requestAnimationFrame จะหยุดวาด |

ตัวตรวจไอเทมทำงานได้ทั้งสองโหมด (ถ้าเกมยังอัปเดต DOM อยู่) ถ้าเกมหยุดอัปเดตข้อความเมื่อซ่อนจริง ให้ใช้โหมดรันต่อเต็มที่

## หมายเหตุ

- เกมโหลดตรงจากเว็บจริง ไม่ผ่าน proxy แต่ละเกมแยกคุกกี้/ล็อกอินจากกัน
- โปรแกรมอ่านข้อความและข้อมูลเครือข่ายของเกมเฉพาะในเครื่องคุณเพื่อตรวจไอเทม ไม่ส่งออกไปที่อื่น
- ข้อมูลที่จำไว้ (รายการเกม ตั้งค่า ไอเทมสะสม) อยู่ในโฟลเดอร์ข้อมูลผู้ใช้ของ Electron
- เกมออนไลน์บางเกมห้ามใช้โปรแกรมช่วยเล่นอัตโนมัติ โปรแกรมนี้เพียงอ่านและแจ้งเตือน ไม่ได้ควบคุมหรือกดอะไรแทนผู้เล่น
